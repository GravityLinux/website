What you get

A real desktop

KDE Plasma on Wayland, on top of a Fedora base you already know.

Native GPU acceleration

A working display controller and GPU driver, so the desktop, your browser, and your games run on the hardware.

Upstream first

Our long-term goal is to land everything upstream. That is the only practical way to keep a project like this sustainable.

Built responsibly

Every line is written by clean-room reverse engineering. We never look at Apple source code or disassembly, and we publish enough of our process for anyone to check that for themselves.
